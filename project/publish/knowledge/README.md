# Project knowledge

The Publish panel's copy writer reads this file before it writes any post. The file is yours: the installer adds it once and never overwrites it.

- **What goes here:** everything about your brand. The skill in `/publish/skill/` covers writing craft and platform rules for any brand.
- **Who wins:** this file wins over the skill on voice. The skill's honesty rules and hard platform limits win over this file.
- **Privacy:** project files sync to Kino's cloud. Keep internal-only material (unreleased dates, partner terms, private numbers) in a private agent skill on your machine, and only name that skill under "Skills to load".
- **Filling it in:** replace each `Example:` line with your own, or delete it. The copy writer ignores lines that start with `Example:`. An empty section tells it to use the skill's defaults.

## Who we are

One or two lines: who makes this, what it is, who it is for.

Example: We are Fernhollow Bikes, a 6-person workshop that builds steel trail bikes for weekend riders.

## Voice and tone

How you sound, and whether you write as "we" or "I".

Example: "We". A mechanic talking to a rider: short sentences, dry, no hype.

## Words and punctuation

Words you never use, spelling, punctuation preferences.

Example: Never "epic" or "shred". US English. No semicolons.

## Names

How to write product, company and people names, exactly.

Example: Fernhollow Bikes (not FH), Trail 2 (not Trail II).

## Product facts

Versions, prices, requirements and numbers that copy may state. Date each line.

Example: 2026-11-01: the Trail 2 ships with FP-22 pads and 180 mm rotors.

## Links and handles

Every link and @handle that copy may use, one per line, with what it is for. They are copied character for character.

Example: Parts list: https://fernhollow.example/trail-2/brake-pads

Example: YouTube and Instagram: @fernhollowbikes

## Never claim

Claims, comparisons and topics to stay away from.

Example: No ship dates for the Trail 3. Never "lifetime" about pads or tires.

## Skills to load

Agent skills the copy writer loads before writing, and what each one is for. Private material that must not sync belongs in one of these.

Example: fernhollow-facts (private): prices, dealer list, unreleased models.

## Rewrite pass

A style pass to run on every option before it is saved, if you use one.

Example: Run the plain-style skill on every title and caption. Save the final text only.

## Only for this video

Lines that apply to this one video, or that override a section above for it. Date each line.

Example: 2026-11-19: this video shows the 2027 frame. Call it "the new frame", no model name.
